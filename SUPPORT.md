# Support / 支持

[English](#english) | [中文](#中文)

## English

### Usage questions

Search existing [Discussions](https://github.com/WhiteMatrixTech/agent-launcher/discussions) first. If the question is not already answered, start a new discussion and include your operating system, Agent Launcher version, CLI name and version, and the behavior you expected.

### Bugs and feature requests

Use the structured [issue forms](https://github.com/WhiteMatrixTech/agent-launcher/issues/new/choose). Remove API keys, tokens, personal paths, and private conversation content from screenshots and logs. A minimal reproduction is more useful than a complete config directory.

### Security and conduct

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](./SECURITY.md). Report Code of Conduct concerns privately as described in [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).

### Scope

This project can help with Agent Launcher behavior and its configuration output. Questions about model access, provider billing, account bans, or bugs in an upstream CLI should be directed to that provider or CLI project.

## 中文

### 使用问题

请先搜索已有的 [Discussions](https://github.com/WhiteMatrixTech/agent-launcher/discussions)。如果没有答案，再发起新讨论，并提供操作系统、Agent Launcher 版本、CLI 名称和版本，以及预期行为。

### Bug 和功能建议

请使用结构化的 [Issue 表单](https://github.com/WhiteMatrixTech/agent-launcher/issues/new/choose)。提交截图和日志前，务必删除 API Key、Token、个人路径和私人对话内容。最小复现通常比完整配置目录更有帮助。

### 安全和社区行为

不要在公开 Issue 中报告漏洞，请按照 [SECURITY.md](./SECURITY.md) 操作。行为准则相关问题请按 [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) 中的方式私下报告。

### 支持范围

本项目可以协助排查 Agent Launcher 的行为及其生成的配置。模型权限、服务商计费、账号封禁或上游 CLI 自身缺陷，应联系对应服务商或 CLI 项目。
